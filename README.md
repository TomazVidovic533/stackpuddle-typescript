# StackPuddle TypeScript SDK

Planned TypeScript authoring SDK for [StackPuddle](https://github.com/TomazVidovic533/stackpuddle).

The SDK is intended to let developers describe application stacks in code and produce the shared versioned model consumed by the StackPuddle engine and CLI.

## Status

Early development. This repository currently contains only this introductory README. No installable release is available yet.
